可以把 Claude Code、DeepSeek Harness、Pi、Grok Build 等不同厂家的顶级 Harness，直接接进 Codex 里统一切换使用。  
  
切换之后 Codex 原本的 Thread、Diff、工具状态、审批、Fork、上下文压缩等交互都还在，不需要重新适应一套工作流。  
  
它甚至还能做跨 Agent 协作：  
  
让 Codex 负责写代码  
→ @ Claude Code 单独做 Review  
→ @ Pi 专门调查 Bug  
  
每个 Agent 都会自动创建独立 Thread，任务彼此隔离，但又能在同一个 Codex 界面里协作，再也不用同时开几个终端窗口来回切了。  
  
开源项目：BytePioneer-AI/codex-host
