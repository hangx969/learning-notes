# 证书管理

## 定义

证书管理是对 TLS 证书及私钥的申请、身份校验、分发、存储、轮换、续期、撤销和审计。Kubernetes 中通常由控制器把证书生命周期声明为资源，并把签发结果写入 Secret 供 Ingress 或工作负载使用。

## 核心要点

- 证书链包含 Root CA、中间 CA 和终端实体证书，不同层级的信任与签发职责不同。
- 自动签发仍依赖域名或身份控制权验证；ACME 常用 HTTP01 和 DNS01。
- 证书、私钥、CA 账号密钥和 DNS API 凭据都属于敏感资产，应最小授权、加密备份并审计访问。
- 自动续期需要监控 Certificate 状态、到期时间、签发请求、Challenge 和控制器健康。
- Secret 的作用域受 Namespace 限制；共享通配符证书时必须显式设计安全的分发机制。
- 生产签发前应使用 Staging 完整验证，避免因配置错误触发 CA 速率限制。
