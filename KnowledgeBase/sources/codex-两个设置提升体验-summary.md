# Codex 两个体验设置 来源摘要

## 元信息
- **原始文档**：[[AI/Codex/Codex-两个设置提升体验]]
- **领域**：AI 编程助手 / Codex 配置
- **摄入日期**：2026-09-05

## 摘要
本文给出两项 Codex 使用建议：在 `config.toml` 中开启普通模式的主动需求澄清，以及会话前通过读取 Juice 值的提示检查模型输出是否异常。前者是可操作的配置项；后者属于作者的经验性质量观察，不应替代测试、审查或验收。

## 关键知识点
1. 在 `[features]` 下设置 `default_mode_request_user_input = true`，可让普通模式在需求不明确时请求用户澄清。
2. 主动澄清适用于复杂、约束不完整或存在多种实现取舍的任务，可在执行前减少返工。
3. 文中提供了一个对 Juice 值进行算术计算的 XML 提示，用作会话前的非正式输出自检。
4. Juice 不是公开的质量指标；关键任务的输出质量应由可复现测试、代码审查和验收标准确认。
